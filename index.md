## 1. Введение

Хостинг — это услуга размещения файлов сайта на сервере, который подключён к интернету круглосуточно. Без хостинга сайт существует только на локальном компьютере и недоступен другим пользователям. Бесплатный хостинг позволяет разместить сайт без денежных затрат, но накладывает ограничения на ресурсы, технологии и стабильность работы.

В рамках проекта я рассмотрел десять бесплатных хостинг-платформ, сравнил их по ключевым параметрам, выделил достоинства и недостатки, а также определил, какой вариант оптимален для учебного статического сайта. Отдельно я проверил, как работает размещение проекта прямо на GitHub Pages — без сторонних серверов и без платных тарифов.

**Цель проекта:** определить лучший бесплатный хостинг для учебного проекта и обосновать выбор.

**Задачи проекта:**
1. Изучить, что такое хостинг и какие бывают типы хостинга.
2. Составить список бесплатных хостинг-платформ.
3. Сравнить платформы по параметрам: поддержка языков, лимиты, стабильность, наличие рекламы.
4. Построить таблицы и диаграммы для наглядности.
5. Сделать вывод и выбрать лучший вариант.

## 2. Что такое хостинг и какие он бывает

Хостинг можно разделить на несколько типов:

- **Статический хостинг** — отдаёт готовые файлы (HTML, CSS, JS, изображения). Серверная логика отсутствует.
- **Хостинг с поддержкой PHP/MySQL** — позволяет запускать скрипты и работать с базами данных.
- **VPS/VDS** — виртуальный сервер, где пользователь сам настраивает окружение.
- **Serverless-платформы** — позволяют запускать отдельные функции без управления сервером.

Для учебного проекта чаще всего достаточно статического хостинга: он проще, быстрее и не требует администрирования.
