# Сравнение бесплатных хостингов

| Сервис | Плюсы | Минусы | PHP? |
|--------|-------|--------|------|
| **GitHub Pages** | Бесплатно, не засыпает, HTTPS, git push | Только статика, нет PHP/MySQL, лимит 100 ГБ/мес | ❌ |
| **Cloudflare Pages** | Трафик не ограничен, serverless-функции | Нет классического PHP, для новичка сложно | ❌ |
| **InfinityFree** | PHP + MySQL, 5 ГБ, без рекламы | Медленно, нет поддержки, нестабильно | ✅ |
| **Vercel** | Хорош для React/Next.js | Только личное использование, PHP нет | ❌ |
| **Render** | 750 часов/мес | Засыпает через 15 минут, карта нужна | ❌ |

**Вывод:** если сайт статический — GitHub Pages. Если нужен PHP — придётся смотреть в сторону InfinityFree, но это боль.
